KDD Cup Intrusion Detection Notebook

Overview

This repository contains a research-oriented Jupyter notebook for network intrusion detection using the KDD Cup dataset family. The workflow covers dataset conversion/loading, preprocessing, categorical feature mapping, class imbalance treatment, feature selection, model training, and validation.

The notebook has been structured for clarity and reproducible top-to-bottom execution without changing core modeling logic.

Dataset Description (KDD Cup Context)

The workflow uses the following files:





Raw source data:





kddcup.data_10_percent.gz



corrected.gz.zip (contains .gz test data)



Processed/intermediate data generated by notebook:





KDD_CUP_train.csv



KDD_CUP_test.csv



Additional validation input:





validate_data.csv

The notebook preserves the original loading/conversion sequence (.gz/.zip -> .csv) for consistency with prior results.

Methodology (Brief)





Import libraries and set random seeds



Convert compressed raw inputs to CSV



Load train/test data with full KDD column schema



Clean and normalize dtypes



Consolidate labels into attack categories



Map categorical variables (protocol_type, flag, service)



Split and scale data



Handle class imbalance (SMOTE + under-sampling)



Perform feature selection (HBA-ABC routine)



Train/evaluate classifier and validate on external data

Results

The notebook computes standard classification metrics (accuracy, precision, recall, F1, and related reports/curves). Final values are produced directly in notebook outputs.

How To Run





Place the notebook and dataset files in the same working directory (or keep paths consistent with current notebook references).



Create and activate a Python environment.



Install dependencies:

 pip install -r requirements.txt



Launch Jupyter:

 jupyter notebook



Open the notebook and run:





Kernel -> Restart & Run All

Run on Google Colab





Upload Copy_of_GitHub.ipynb to Colab.



Upload dataset files (kddcup.data_10_percent.gz, corrected.gz.zip, validate_data.csv) to the Colab runtime working directory, or mount Drive and adjust file paths.



Run the optional Google Colab Environment setup cell near the top of the notebook.



Run all cells in order (Runtime -> Run all).
